# Commute Dashboard

A personal commute dashboard web application that provides a quick-glance summary of expected weather conditions and rail travel information for a configured commute. If the destination is London, Transport for London (TfL) data is also surfaced.

## Structure

```
├── infra/      # AWS CDK app (TypeScript)
├── backend/    # Lambda container (Node.js / TypeScript)
└── frontend/   # React + Vite SPA (TypeScript)
```
